# ReloadedWaffle

Vape-style click GUI script for RELOADED — ESP, camera aim (smoothed), silent aim via namecall hooks, config save/load.

## Execute

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/vrcdev/ReloadedWaffle/main/loader.luau"))()
```

## Controls

- **Delete** — toggle menu
- **End** — unload
- Left-click module = toggle · Right-click = expand settings
